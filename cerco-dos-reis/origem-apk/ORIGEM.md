# Recursos recuperados do APK Cerco dos Reis 1.0.0
Esses arquivos foram extraídos de `downloads/cerco-dos-reis-1.0.0.apk` pertencente ao próprio repositório do usuário.
São arte, CSS e HTML empacotados no APK original, preservados sem alteração.
Isso NÃO representa um backup do banco de dados, autenticação, pagamentos, lógica do servidor ou do código JavaScript do site Work.
Esta pasta é parte de uma migração em preparação; não substitui o jogo original.
